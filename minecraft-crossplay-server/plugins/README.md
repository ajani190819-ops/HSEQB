# Minecraft Server Plugins Directory

This directory contains the plugins that power the Bedrock + Java cross-play server:

1. **`Geyser-Spigot.jar`** — Translates Bedrock network packets to Java packets.
   - Source: [GeyserMC Website](https://geysermc.org/download#geyser)
2. **`floodgate-spigot.jar`** — Allows Bedrock players to join using their Xbox gamertag without needing a separate Java account.
   - Source: [GeyserMC Floodgate](https://geysermc.org/download#floodgate)
3. **`ViaVersion.jar`** — Enables players on older and newer Minecraft versions to connect seamlessly.
   - Source: [ViaVersion Hangar / SpigotMC](https://hangar.papermc.io/ViaVersion/ViaVersion)

Run the included `download_server_and_plugins.bat` (Windows) or `./download_server_and_plugins.sh` (Mac/Linux) to automatically fetch these plugins.
